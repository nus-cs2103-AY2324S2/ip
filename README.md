## Instructions

Prerequisites: JDK 11, update Intellij to the most recent version.

1. Download the latest version [here](https://github.com/moguries/ip/releases)
2. Open Terminal
3. From the folder that 'Fatnom.jar' was downloaded into, run **java -jar Fatnom.jar**
4. All good to go!
